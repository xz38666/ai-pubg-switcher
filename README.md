# ИИ и PUBG

Программа для Windows с установщиком, ярлыком и автоматическим запуском фонового PAC-сервера при входе в систему.

![Иконка](payload/AI-icon.png)

## Скачать и установить

Откройте [последний релиз](../../releases/latest), скачайте **AI-PUBG-Setup.exe** и нажмите **«Установить и включить»**. Подтвердите запрос Windows, затем перезапустите браузер и проверьте нужный ИИ-сервис.

Требования: Windows 10/11 x64, .NET Framework 4.8 и текущая учётная запись с правами администратора. Перед установкой закройте COMSS AI, если он запущен.

После установки появляется ярлык **«ИИ и PUBG»**. Фон запускается при входе в Windows; открывать окно и нажимать кнопки после перезагрузки не нужно. Закрытие окна оставляет фон работающим.

## Как работает

- Встроенный PAC направляет сайты из списка через прокси COMSS; остальные соединения — напрямую.
- Основные домены Steam, PUBG, Krafton и BattlEye имеют исключения DIRECT.
- Локальный сервер слушает только `127.0.0.1:19825` и раздаёт PAC. Это не VPN и не собственный удалённый прокси.
- Правила включены в сборку и автоматически не обновляются. Доступ зависит от сети и доступности серверов COMSS.
- «PUBG — выключить» отключает WinINet-прокси и автозапуск ИИ. «ИИ — включить» возвращает их.

Настраиваются WinINet в HKCU/HKLM и запись автозапуска `AI-PUBG-PAC`. DNS, hosts, VPN, WinHTTP и индивидуальные настройки прокси приложений не изменяются. Отдельная установка COMSS не требуется; доступность его серверов программа не гарантирует.

## Удаление и восстановление

Удалите **«ИИ и PUBG»** через Параметры Windows → Приложения либо пункт «Удалить» в меню «Пуск». Удаление восстановит настройки прокси, сохранённые перед первым включением программы. Копия останется в `%LOCALAPPDATA%\AI-PUBG-Switcher-backup-ДАТА`.

Программа устанавливается в `%LOCALAPPDATA%\AI-PUBG-Switcher`. Не удаляйте эту папку вручную, пока используется локальный PAC. Если настройки прокси менялись после установки, учитывайте, что восстановление возвращает сохранённое состояние.

## Сборка из исходников

В PowerShell из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `AI-PUBG-Setup.exe`. Используется системный C#-компилятор .NET Framework; Python и Node.js для сборки и работы не нужны. Исходник приложения — `Switcher.cs`, установщика — `Setup.cs`, правила — `comss-source.pac`.

## Проверено

Сборка приложения и установщика, извлечение и SHA256 вложенных файлов, отображение окна установщика, 18 проверок маршрутов PAC. Пользователь подтвердил работу PUBG с включённым ИИ и автозапуск после перезагрузки на исходном компьютере. Установка на другом ПК пока не проверена.

В дистрибутиве нет настроек, резервных копий или учётных данных исходного компьютера. Цифровой подписи у установщика нет. Проект не является официальным приложением COMSS или PUBG.
